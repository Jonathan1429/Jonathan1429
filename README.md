## 🚀 Proyecto Destacado

### Review

Aplicación Android desarrollada en Kotlin, estructurada bajo el patrón MVVM y principios de Clean Architecture.

**Características técnicas:**

- Arquitectura multicapa bien definida
- Separación clara entre presentación, dominio y datos
- Lógica de negocio desacoplada
- Implementación de testing unitario en casos de uso
- Publicada en Google Play Store
